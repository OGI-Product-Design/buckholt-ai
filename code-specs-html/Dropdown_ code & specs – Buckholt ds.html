    Dropdown: code & specs

    • Usage
    • Style
    • Code & specs
    This page documents the expected code output and structure necessary to display dropdowns correctly in the UI.
    JS enhancements
    This component uses JavaScript to enhance its functionality and behaviour. Additional setup may be required to ensure it works as intended within your implementation. Below is the JS used for this component.
    dropdown.js

    Dropdown base code

    The base dropdown relies on a specific HTML structure and a set of CSS classes to render and function correctly.

    The example below outlines the main elements required to create a basic dropdown. The .input class acts as the wrapper and contains the .input-label and .response sections. This structure ensures consistent styling and alignment with other form controls.

    To define the dropdown, the .dropdown-input class is applied to the .response container. Inside this, the .dropdown element contains both the .dropdown-toggle button and the .dropdown-menu list of options.
    The .dropdown-menu-panel class handles the styling of the dropdown options as .dropdown-menu is also used to control the menu component.

    <div class="input">
    <div class="input-label">
        <label for="dropdown-example" class="form-label">Dropdown label text</label>
    </div>

    <div class="response dropdown-input">
        <div class="dropdown">
            <button id="dropdown-example" class="dropdown-toggle" type="button" data-bs-toggle="dropdown" aria-expanded="true">
                <span class="dropdown-label">Choose an option…</span>
            </button>

            <ul class="dropdown-menu dropdown-menu-panel" role="menu" aria-labelledby="dropdown-example">
                <li id="dropdown-option-1" class="dropdown-item" role="option" aria-label="Option 1" aria-selected="false" tabindex="0">
                    Option 1

    Multiselect

    The multiselect variant of the dropdown uses the same overall structure as the base component. The only difference lies in the construction of each .dropdown-item.

    Instead of rendering plain text, each list item contains a checkbox input paired with a label. This allows users to select more than one option at a time.

    Validation message
    html 
    <div class="input">
    <div class="input-label">
        <label for="multiselectExample" class="form-label">Dropdown label text</label>
    </div>

    <div class="response dropdown-input">
        <div class="dropdown">
            <button id="multiselectExample" class="dropdown-toggle" type="button" data-bs-toggle="dropdown" data-bs-auto-close="false" aria-expanded="false">
                <span class="dropdown-label">Choose some options</span>
            </button>

            <ul class="dropdown-menu dropdown-menu-panel" role="menu" aria-labelledby="multiselectExample">
                <li id="dropdown-option-1" class="dropdown-item" role="option" aria-label="Option 1" aria-selected="false" tabindex="0">
                    <input class="form-check-input" type="checkbox" id="checkbox-option-1">
                    <label class="form-check-label" for="checkbox-option-1">Option 1</label>
                </li>
                <li id="dropdown-option-2" class="dropdown-item" role="option" aria-label="Option 2" aria-selected="false" tabindex="0">
                    <input class="form-check-input" type="checkbox" id="checkbox-option-2">
                    <label class="form-check-label" for="checkbox-option-2">Option 2</label>
                </li>
                <li id="dropdown-option-3" class="dropdown-item" role="option" aria-label="Option 3" aria-selected="false" tabindex="0">
                    <input class="form-check-input" type="checkbox" id="checkbox-option-3">
                    <label class="form-check-label" for="checkbox-option-3">Option 3</label>
                </li>
            </ul>    
        </div>
    </div>

    Making selections

    Once one or more options are chosen, the selections are displayed as tags inside a .tag-set container within the .dropdown. Each tag shows the option’s title and includes a close button, allowing users to remove a selection directly without reopening the menu.

    The .tag-set is placed above the .dropdown-toggle button. Tags use the .tag-dismissible style so that they can be individually removed.

    Refer to the tag page for more details.

    <div class="dropdown">
    <div class="tag-set">
        <span class="tag tag-dismissible expressive-light">
            <span class="tag-label">Option 1</span>
            <button type="button" class="btn-close btn-close-sm" aria-label="Close"></button>
        </span>

        <span class="tag tag-dismissible expressive-light">
            <span class="tag-label">Option 2</span>
            <button type="button" class="btn-close btn-close-sm" aria-label="Close"></button>
        </span>
    </div>

    <button id="multiselectExample" class="dropdown-toggle" type="button" data-bs-toggle="dropdown" aria-expanded="true">...</button>
    <ul class="dropdown-menu dropdown-menu-panel" role="menu" aria-labelledby="multiselectExample">...</ul>

    Select all

    The multiselect dropdown supports a select all option, allowing users to quickly select or clear all items in the list.

    To enable this feature, the first .dropdown-item is reserved for the select all checkbox. Notable features of this implementation include:

    • Each list item uses a unique numerical id (dropdown-option-1, dropdown-option-2, etc.). The select all option must always use an id ending in -0 (dropdown-option-0) to distinguish it from standard items.
    • A .dropdown-divider is placed immediately after the select all option to visually separate it from the rest of the list.
    • The select all item follows the same structure as other list items, with a .form-check-input checkbox and .form-check-label.

    The select all checkbox also supports an indeterminate state, which is displayed when one or more (but not all) options are selected.

    Validation message
    html 
    <li id="dropdown-option-0" class="dropdown-item" role="option" aria-label="All" aria-selected="false" tabindex="0">
    <input class="form-check-input" type="checkbox" value="" id="checkbox-all">
    <label class="form-check-label" for="checkbox-all">All</label>
</li>
<li class="dropdown-divider"></li>

    Collapsible tags

    When a large number of options are available, displaying every selected item as an individual tag can quickly become overwhelming. To handle this, the dropdown supports a collapsible tags variant.

    This behaviour is controlled with data attributes on the .dropdown element:

    • data-collapse-threshold — defines the number of selected options at which tags collapse into a summary tag.
    • data-summary-label — allows the default label text of selected to be customised (for example, “chosen” or “picked”).

    When the threshold is reached, the .tag-set is replaced with a single summary tag. The label shows the count of selected options alongside the chosen summary word. For example, if five items are selected and the summary label is set to “chosen”, the tag will read “5 chosen”.

    Validation message
    html 
    <div class="dropdown" data-collapse-threshold="2" data-summary-label="selected">
    ...
</div>

    Type-ahead

    The type-ahead variant allows users to quickly filter options by typing directly into the dropdown.

    Key characteristics of this variant include:

    • The .dropdown-toggle is implemented as an <input> element, providing a text field for user input.
    • An .input-clear button is placed immediately after the input. It appears once text has been entered and allows users to clear their selection with a single click.
    • The .dropdown-menu contains the full list of .dropdown-item options, which are filtered in response to the text typed into the input.
