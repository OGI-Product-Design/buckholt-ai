Buckholt runtime verification harness

Every block below is the source-verified canonical markup from components/<component>/examples.html, copied verbatim, rendered against the documented runtime contract. Nothing inside a canonical block has been rewritten, normalised or repaired. The grey framing, headings, badges and test controls are harness chrome added by runtime-verification.js and sit outside the canonical markup.

This page answers one question: does the documented HTML render and behave correctly against css/buckholt.css, css/buckholt-ai-fixes.css, Bootstrap 5.1.3, Proxima Soft and the Buckholt Font Awesome kit? It does not answer whether the markup is faithful to Buckholt - that is source verification, already recorded in verification/component-source-status.md.

Classify anything that looks wrong with the categories in verification/runtime-verification-framework.md before changing anything. Do not patch a defect on this page.
