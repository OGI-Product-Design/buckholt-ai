# Breadcrumb

## Verification

Source-verified against the Buckholt Breadcrumb Usage, Style and Code & specs HTML pages supplied on 7 September 2026. `examples.html` is the canonical source for exact Breadcrumb DOM structure.

## Purpose

Breadcrumbs show a user's current position within a site's structure and allow movement to parent/previous levels. They are secondary navigation and do not replace primary navigation.

## Usage

Use Breadcrumbs for deeper hierarchical products or experiences where positional context is useful. Buckholt documents location-based and path-based approaches; choose one approach consistently within a product.

## Canonical markup

Do not reconstruct Breadcrumb markup from prose. Use `examples.html` exactly.

The base Code & specs source uses:

```text
nav[aria-label="breadcrumb"]
└─ ol.breadcrumb
   ├─ li.breadcrumb-item
   │  └─ a.breadcrumb-link
   └─ li.breadcrumb-item.active[aria-current="page"]
```

The current page is the final, non-link item and uses `.active` plus `aria-current="page"`.

## Overflow menu

The Code & specs source provides a full overflow example. It composes Breadcrumb with Buckholt Menu markup and a tooltip on the overflow item. Preserve that exact structure from `examples.html`; do not substitute a different overflow/menu trigger pattern.

## Dividers

Dividers are generated by the component rather than written between Breadcrumb items. The Code & specs source demonstrates changing the divider with the inline custom property:

```html
<nav style="--breadcrumb-divider-icon: '>';" aria-label="breadcrumb">
    ...
</nav>
```

The source page also contains an SCSS example. This repository intentionally does not use SCSS, and SCSS must not be copied into canonical `examples.html` or implementation guidance.

## Long trails

Buckholt Usage guidance says Breadcrumbs should not wrap onto a second line. Use the documented overflow approach for long trails rather than inventing custom truncation.

## Accessibility

Preserve the documented navigation landmark, semantic list, link destinations and `aria-current="page"` on the current item. Dividers are presentation, not content.

## Agent rules

- Use `examples.html` as canonical DOM evidence.
- Use `<nav aria-label="breadcrumb">`, `.breadcrumb`, `.breadcrumb-item` and `.breadcrumb-link` exactly as documented.
- Keep the current page non-linked and marked `.active[aria-current="page"]`.
- Use the exact documented overflow-menu composition when overflow is required.
- Do not add divider characters directly to item markup.
- Never copy the source SCSS example into this repository's implementation path.
- Do not recreate Breadcrumb spacing, typography or overflow styling with local CSS.
