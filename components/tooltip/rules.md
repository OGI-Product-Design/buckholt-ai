# Tooltip

## Verification

Source-audited against the Buckholt Tooltip Usage, Style and Code & specs HTML pages supplied on 7 September 2026. Use `examples.html` for exact documented trigger, generated plugin markup and initialization code.

## Purpose

Tooltip provides a short explanation for a UI trigger, especially where an icon-only or unfamiliar control needs additional context. It is supporting information, not a replacement for essential visible labels or instructions.

## Canonical source forms

The Code & specs source documents three different layers and they should not be conflated:

1. **Trigger markup** — a control with `data-bs-toggle="tooltip"` and `data-bs-title`.
2. **Bootstrap-generated Tooltip DOM** — `.tooltip`, `.tooltip-arrow` and `.tooltip-inner`; this is generated by the plugin rather than authored as normal page markup.
3. **Initialization JavaScript** — creates `bootstrap.Tooltip` instances with the documented `offset: [0, 4]` and `delay: { show: 800, hide: 100 }`.

The source also documents `data-bs-placement` for top, right, bottom and left examples.

Do not manually insert generated Tooltip DOM into production just because it appears in Code & specs; let Bootstrap generate it from the trigger/init code.

## Dependencies

Tooltip requires Bootstrap's JavaScript bundle. Use the documented initialization when implementing Buckholt Tooltip behaviour rather than creating a separate local Tooltip system.

## Accessibility and content

Keep Tooltip copy concise and directly related to the trigger. Essential task information must remain available without relying solely on hover. Keyboard-focusable triggers must also expose the Tooltip behaviour appropriately.

## Agent rules

- `examples.html` is canonical evidence for Tooltip trigger markup, generated plugin markup and initialization code.
- Distinguish authored trigger HTML from Bootstrap-generated DOM.
- Preserve the documented offset/delay/placement configuration unless product requirements explicitly establish a different adapter.
- Use Bootstrap Tooltip behaviour and Buckholt styling rather than recreating Tooltips locally.
