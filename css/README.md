# Buckholt compiled CSS

Place the current compiled Buckholt stylesheet in this directory as:

`buckholt.css`

This file is intentionally treated as the browser-facing implementation truth for AI validation. The Button showcase at `test/button-showcase/index.html` references it directly.

The source file currently being used for the AI specification is the compiled `buckholt.css` supplied from the existing Buckholt project.

Do not ask an AI agent to recreate this stylesheet from `tokens.json`; use the real compiled output.
