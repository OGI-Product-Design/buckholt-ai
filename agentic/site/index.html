OGI UX team · proposed workflow

Designers decide at two gates; agents do the work in between

How the OGI UX team proposes to run design with twelve agents: what each agent does, where people decide, and how the work reaches product and engineering.

The workflow

Work moves down the page. The two gates are where designers, the PM and an engineer decide; agents do everything between them.

Three principles

Designers lead

Designers set the direction, make the anchor screens and decide at both gates.

Agents extend and check

Agents do the work between the gates: they explore, extend from the anchors, check and hand over. People review what they produce.

Buckholt never changes

Agents build with Buckholt as it is. Anything Buckholt does not have is a flagged extension, registered for review.

The twelve agents

Each agent has one job and a rules file. Select an agent to see its rules.
