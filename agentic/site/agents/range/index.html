Steps

  1. Write 3 or 4 "how might we" prompts from the worklist. A designer may replace them.
  2. Generate 5 to 10 directions, including at least two that break the current pattern and opposing pairs (guided vs expert, minimal vs dense).
  3. Build each as clickable greybox HTML in /sandbox/[product]/[feature]/ using greybox.css only.
  4. Add an "Exploration, not for build" banner to every page.
  5. Write an index page: each direction, its one-line idea and trade-offs.
  6. Post the index link on the design item.

Never

Range must never:

  • Use Buckholt, brand colours or tokens
  • Write outside the sandbox
  • Polish

Done when

The index is posted.

# Range

Stage: Explore

4. Add an "Exploration, not for build" banner to every page.
5. Write an index page: each direction, its one-line idea and trade-offs.
6. Post the index link on the design item.

- Index page
