Agents

Twelve agents, grouped by stage. Each one has a single job, reads defined sources, and stops at a human check.

Foundation

Archive

Archive

Keeps design context accurate and the same in the repo and SharePoint.

Tool: Cursor, plus a weekly scheduled run

Discover

Brief

Brief

Turns a product feature into a UX problem and chooses the route.

Tool: Microsoft 365 Copilot

Insight

Insight

Synthesises research and behaviour evidence.

Tool: Microsoft 365 Copilot, plus a Cursor step for LogRocket

Map

Map

Turns findings into structure and a design worklist.

Tool: Microsoft 365 Copilot and Lucid

Explore

Range

Range

Generates many quick, deliberately rough directions.

Tool: Cursor, sandbox only

Critic

Critic

Stress-tests the explorations before the shortlist gate.

Tool: Cursor

Design

Extend

Extend

Builds out the design from the designers' anchor screens.

Tool: Cursor + Figma MCP (the only agent with write access)

Align

Align

Checks consistency across all Figma work, designers' work included.

Tool: Cursor + Figma MCP (read only)

Prototype

Build

Build

Turns signed-off designs into prototypes.

Tool: Cursor

Audit

Audit

Runs automated quality checks before people see a prototype.

Tool: Cursor + Playwright + axe

Observe

Observe

Supports usability testing around the sessions.

Tool: Cursor

Handoff

Relay

Relay

Hands over to engineering, then checks what was built.

Tool: Cursor + Azure DevOps MCP
