Checks consistency across all Figma work, designers' work included.

Stage Design
Tool Cursor + Figma MCP (read only)

At a glance

Triggered by

  • Each Extend batch
  • A designer's request
  • Weekly on active files

Reads

  • The named Figma pages only
  • The product library
  • The styling mode
  • The extensions register

Produces

  • Issue list by severity with frame links, posted on the design item

Human gate

  • Designers decide what is a mistake and what is deliberate.

Steps

  1. Check for detached instances and styles not from the library.
  2. Check spacing and sizes against the token scale.
  3. Check for wrong or one-off text styles.
  4. Check wording against the product pack's terms.
  5. Check for styling-mode mismatches, such as Buckholt parts in a legacy screen.
  6. Check extension components are flagged and register entries have both halves.

Never

Align must never:

  • Fix anything
  • Change files

Done when

The report is posted.

/agents/align.md 
# Align

Stage: Design
Tool: Cursor + Figma MCP (read only)
Job: Checks consistency across all Figma work, designers' work included.

## Triggered by
- Each Extend batch
- A designer's request
- Weekly on active files

## Reads
- The named Figma pages only
- The product library
- The styling mode
- The extensions register

## Steps
1. Check for detached instances and styles not from the library.
2. Check spacing and sizes against the token scale.
3. Check for wrong or one-off text styles.
4. Check wording against the product pack's terms.
5. Check for styling-mode mismatches, such as Buckholt parts in a legacy screen.
6. Check extension components are flagged and register entries have both halves.

## Produces
- Issue list by severity with frame links, posted on the design item

## Human gate
Designers decide what is a mistake and what is deliberate.

## Never
- Fix anything
- Change files

## Done when
The report is posted.
