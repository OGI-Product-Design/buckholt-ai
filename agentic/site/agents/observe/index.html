Observe Observe

Supports usability testing around the sessions.

Stage Prototype
Tool Cursor

At a glance

Triggered by

  • Audit passing and sessions being booked

Reads

  • The prototype
  • Success measures
  • Teams recordings
  • LogRocket baselines

Produces

  • Test plan
  • Tagged clips
  • Findings report

Human gate

  • Designers run the sessions and decide what changes.

Steps

  1. Draft the test plan and script from the success measures and test tasks.
  2. After sessions, tag recordings by task, success, hesitation, error and quote.
  3. Summarise per task and compare with the LogRocket baselines.
  4. Write findings: issue, how many participants, severity, suggested change, and whether it goes back to Extend or Build.

Never

Observe must never:

  • Run sessions
  • Treat one participant's comment as a finding
  • Keep personal data

Done when

Findings are posted and routed.

# Observe

Stage: Prototype
Tool: Cursor
Job: Supports usability testing around the sessions.

## Produces
- Test plan
- Tagged clips
- Findings report

Designers run the sessions and decide what changes.

## Never
- Run sessions
- Treat one participant's comment as a finding
- Keep personal data

Findings are posted and routed.
