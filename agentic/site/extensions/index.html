Extensions on this site

This site is built with Buckholt as it is. These parts are not in Buckholt, so they are extensions: prefixed x-, marked data-buckholt="false", styled only with Buckholt tokens, and listed in the extensions register.

Agent tag

The tag is the Buckholt Tag in its stage colour. The extension is the link around it, with its hover and focus states.

Stage colours and contrast

Buckholt has four expressive colour families, so Foundation uses the neutral tag and Handoff shares Prototype’s family. The stage is always named in text as well.

Buckholt’s light expressive Tag colours its label with the family’s deep colour, which is below WCAG AA contrast for two families. On this site the label uses the same family’s rich colour instead. Buckholt’s CSS is not changed.

Code block with copy

Buckholt has no code block. The copy control is a Buckholt ghost Button with the Common actions copy icon, shown only when JavaScript is available.
