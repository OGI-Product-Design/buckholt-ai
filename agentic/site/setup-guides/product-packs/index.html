Product packs

Every agent reads the product pack, so each product needs one before any feature for it can start.

Guide 2 of 9

Who does it

A designer who knows the product, with Laurence or Jon approving.

What you need

  • The product's styling mode: Buckholt, Hybrid or Legacy
  • Its navigation pattern, key screens and terms
  • The repo set up, with /context in place

Steps

  1. Create the pack in /context, one file per product, from the outline below.
  2. Record the styling mode. Build follows it and Align checks against it.
  3. List the product's terms, so Align can check wording.
  4. Open a pull request. Laurence or Jon approves it.
  5. Once it is merged, Archive copies the pack to SharePoint.
