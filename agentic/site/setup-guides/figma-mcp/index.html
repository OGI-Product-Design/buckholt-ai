Figma MCP

Figma MCP lets agents read the designs, and lets one agent, Extend, build them out.

Guide 5 of 11

Who does it

Each designer, on their own machine, once their Figma seat is in place.

What you need

  • Cursor installed
  • A Figma Full seat for anyone running Extend , because it writes
  • Read access to the product's Figma files and libraries for everyone else

Steps

  1. Add the Figma MCP server to Cursor.
  2. Sign in to Figma when Cursor asks.
  3. Check read access: ask Cursor to list the frames on a page you can see.
  4. For Extend only: check write access on a test file.
  5. Set up Code Connect, so Align , Build and Relay can map Figma components to code.

Done when

Cursor can read a named Figma page, and the people running Extend can write to a test file.

Used by

Extend writes. Align , Build and Relay only read. Archive tracks daily calls and warns at 80% of the limit.
