Azure DevOps connectors

Agents read features and write to stories through Azure DevOps, so the work and the record stay in one place.

Guide 9 of 11

Who does it

Laurence or Jon, with an Azure DevOps project administrator, then each person who runs Relay .

What you need

  • The design board set up
  • Microsoft 365 Copilot, for Brief
  • Cursor, for Relay

Steps

  1. Connect Azure DevOps to Microsoft 365 Copilot, so Brief can read features, stories and their fields.
  2. Add the Azure DevOps MCP server to Cursor, so Relay can add UX sections and links to stories.
  3. Limit Relay 's access: it may add to stories and set Design status, but never change engineering statuses or the PM's story text.
  4. Check both: Brief reads a test feature; Relay adds a UX section to a test story.

Done when

A test feature runs from Ready for design to Handed over, with Brief reading it and Relay writing the UX section.

Used by

Brief and Relay .
