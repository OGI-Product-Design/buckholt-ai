Lucid

Lucid holds the journey maps from Discover and the rough flows from Explore.

Guide 8 of 9

Who does it

Each designer.

What you need

  • A Lucid account in the OGI workspace
  • Cursor installed, for Range

Steps

  1. Connect Lucid to Microsoft 365 Copilot, so Map can create and update journey maps.
  2. Add the Lucid MCP server to Cursor, so Range can draw rough flows.
  3. Create a Lucid folder per product for journeys and flows.
  4. Check access: ask Map to open an existing flow.

Done when

Map can save a journey map and Range can read it.

Used by

Map and Range .
