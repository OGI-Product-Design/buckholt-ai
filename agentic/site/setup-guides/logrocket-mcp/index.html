LogRocket MCP

LogRocket gives every feature real baselines, so success measures are based on what users actually do.

Who does it

Each person who runs Insight 's Cursor step, Observe or Relay .

What you need

  • Cursor installed
  • A LogRocket account with access to the products in scope

Steps

  1. Add the LogRocket MCP server to Cursor.
  2. Sign in to LogRocket when Cursor asks.
  3. Check access: ask for the completion rate of a known flow.
  4. Agree which flows each product's success measures use.

Done when

Insight can pull completion, drop-off, error and rage-click baselines for a flow in scope.

Used by

Insight (Cursor step), Observe and Relay .
