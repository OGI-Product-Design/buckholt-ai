## Who does it

Each designer.

## What you need

- A Lucid account in the OGI workspace
- Cursor installed, for {{agent:range}}

## Steps

1. Connect Lucid to Microsoft 365 Copilot, so {{agent:map}} can create and update journey maps.
2. Add the Lucid MCP server to Cursor, so {{agent:range}} can draw rough flows.
3. Create a Lucid folder per product for journeys and flows.
4. Check access: ask {{agent:map}} to open an existing flow.

## Done when

{{agent:map}} can save a journey map and {{agent:range}} can read it.

## Used by

{{agent:map}} and {{agent:range}}.
